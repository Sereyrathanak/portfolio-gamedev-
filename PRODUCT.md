# Product

## Platform

Web

## Stack

React, TypeScript, Vite, and Motion. The project intentionally has no WebGL or Three.js runtime. GitHub Pages deployment is configured through GitHub Actions.

## Users

Game development internship recruiters are the primary audience. Classmates and lecturers are secondary visitors.

## Product Purpose

Present Rith Sereyrathanak as an emerging Unity game developer with a software-engineering education. Success means an internship recruiter can understand that positioning immediately, inspect the current Unity build and supplied gameplay capture, distinguish supporting team software from planned work, and reach the verified GitHub profile.

## Positioning

Unity game developer first, supported by a software-engineering education and verified team-product experience. FirstGame is the dominant proof; Life Goods and Internship Finder are supporting team projects; future Game Development, Mobile Development, and VR capstone work remain explicitly planned.

## Operating Context

Visitors browse a single-page portfolio on desktop or mobile, often quickly and before an interview decision. The first viewport must communicate the discipline and make the work accessible without requiring specialized rendering or interaction.

## Capabilities and Constraints

The opening viewport is portrait-led and directs recruiters to FirstGame or GitHub. Supporting software projects use keyboard-operable tabs. FirstGame uses the supplied Unity gameplay capture, with a code-native scene retained only as a load-failure fallback, and project content remains semantic outside the visual projection. Personal and project images use stable paths under `public/portfolio-assets/`. No unsupplied achievement, personal contribution, role, or result may be implied.

## Evidence on Hand

Confirmed evidence includes Rith's supplied portrait, GitHub profile, email address, and LinkedIn profile; a supplied FirstGame gameplay capture; FirstGame as a Unity 6 keyboard-controlled 3D forest platformer with two playable levels, coins, enemies, moving platforms, C#, and URP; Life Goods as a Khmer-first product-information team project; and Internship Finder as a CADT team final project. No résumé is supplied. The Unity VR capstone, next game-development project, and mobile project are plans only.

## Product Principles

- Lead with Rith’s identity, Unity positioning, and FirstGame.
- Show verified project evidence before broad claims.
- Keep the supplied email, LinkedIn profile, and GitHub profile easy to find and use.
- Mark planned work and missing gameplay media explicitly rather than inventing progress.
- Preserve useful content without WebGL or motion.
- Treat Black Box Playback as the portfolio’s durable visual identity: project evidence leads, theatrical controls support it, and synthetic character imagery does not represent the developer.

## Accessibility & Inclusion

Respect reduced-motion preferences, preserve keyboard-operable project selection, provide visible focus, maintain semantic reading order, and keep all project information available as ordinary HTML alongside the code-native projection.
